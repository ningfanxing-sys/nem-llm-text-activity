Extraction prompts and JSON schemas used in this study.
notice_prompt.txt: prompt for extracting one AEMO market notice.
notice_schema_response_format.json: notice response schema passed to the model.
notice_schema_full.json: full notice validation schema.
article_prompt.txt: article prompt template, filled with each article at run time.
article_schema.json: article extraction response schema.
feature_dictionary.md: ASCII feature definitions, source fields, timing and training-label availability rule.

supplementary_details.md: supplementary details cited in the paper as Supplement A.1-D.2 (tests, timing rules and date parsing, extraction runs, encoding, seeds and windowed references, placebo MAE levels)
README.txt: inventory and descriptions of all files in this folder.
