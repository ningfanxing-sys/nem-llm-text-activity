# Day-first notice feature calculations

The notice models use the same fitted model files, training features, pruning, residual addition and clipping under both timestamp readings. Evaluation features for Event states, Overlap components and Rule parser read DD/MM/YYYY timestamps day first for the main estimates. The corresponding NPL and shifted-placebo inputs use the same feature functions. Delayed inputs apply their specified availability shifts.

Bounded matrix slices are assembled in memory. The equivalence records contain 37 comparisons with zero maximum raw or clipped prediction difference. The verifier reconstructs every saved prediction's daily MAE and the official and further-analysis comparisons under both readings, including seven-day and one-day intervals.

The official export contains nine unavailable comparison slots. The paired comparisons under both readings use the declared arms and day sets and the frozen statistical functions. Descriptive subsets retain their descriptive treatment.
